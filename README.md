# NBMob

농구 덕후를 위한 NBA 뉴스 · 영상 · 이미지 큐레이션 사이트. FotMob 의 농구 버전을 목표로 합니다.

## 구조

```
index.html   메인 페이지 (뉴스 / 영상·이미지 / 팀·선수 허브 / 제보)
style.css    반응형 다크 테마
app.js       뉴스·큐레이션 데이터와 렌더링
assets/      SVG 그래픽 (자체 제작)
```

## 로컬 실행

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Vercel 배포

1. 이 저장소를 Vercel 에 Import
2. Framework Preset: **Other** (빌드 명령 없음, 정적 사이트)
3. Output Directory: 루트 그대로

## 콘텐츠 운영 원칙 (저작권·상표)

- 이 프로젝트는 NBA, 구단, 리그, 선수, 사진/영상 제공자와 제휴되어 있지 않습니다.
- NBA/팀 로고, 공식 경기 영상·사진은 직접 호스팅하지 않습니다.
- 뉴스는 **요약 + 원문 링크** 방식으로 제공합니다.
- 영상은 제공자가 **임베드를 허용한 경우에만** 임베드/링크합니다.
- 이미지·그래픽은 자체 제작(SVG)하거나 라이선스가 명확한 소스만 사용합니다.

`app.js` 의 `NEWS`, `MIX` 배열만 교체하면 콘텐츠가 바뀝니다. 현재 값은 구조 예시입니다.
